# 跑团平台 · 诡秘 D20 定制版

基于开源项目 [paotuan](https://paotuan.github.io/) 二次开发的个人部署版，
构建产物可直接托管在 **GitHub Pages**。

---

## 这个版本加了什么

| 能力 | 说明 |
| --- | --- |
| **诡秘之主 D20 角色卡** | 8 属性（基础/序列增幅/最终值）、生命·理智·灵性·幸运池、三防、途径/序列/位格、46 项技能，等级补正自动换算 |
| **双规则并存** | COC 7 版与诡秘 D20 同时支持，导入人物卡时可选规则，两种卡可以混在同一个团里 |
| **骰娘按规则分流** | COC 走 `d100 ≤ 技能值`，诡秘走 `d20 + 属性 + 等级补正 ≥ 难度`；大成功/大失败看 d20 本身 |
| **Dice! 版指令兼容** | 移植 `guimi_rule.lua`：`.gm` 命令族、手动加值、改判属性、奖励投/惩罚投、`.gmsc` 理智检定、`.gmsn` 摘要、属性生成 |
| **骰娘设置面板** | 群主/主持人可改回复文案、功能开关、理智检定数值，改完广播全群（对应 Lua 顶部那堆可改变量） |
| **群级规则开关** | 群资料 →「启用机器人」→ 骰子规则：`自动 / COC 7版 / 诡秘 D20`，切换后广播给群成员 |
| **我的笔记（玩家可写）** | 重要笔记页新增「我的笔记」，任何玩家都能记线索/NPC/骰点，只存本机浏览器、别人看不到 |
| **主持人分组** | 群主（root）可在群成员里把其他人「设为主持人」，人数不限；额外主持人能发笔记/图片/管 BGM，但**不能踢人、不能解散群** |
| **依赖本地化** | vue / element-ui / vuex / xlsx / mathjs 等全部搬进 `public/vendor/`，不再依赖 cdnjs（国内不再白屏） |
| **自动部署** | `.github/workflows/main.yml` 用官方 Pages Actions，push 即发布 |

完整改动见 **[CHANGES.md](CHANGES.md)**。

## 快速开始

```bash
npm ci                     # 首次
npm run serve              # http://localhost:8080
npm run test:rules         # 人物卡解析 + 骰娘结算 + 规则选择自检
npm run build              # 产物在 dist/
```

> Node 17+ 上构建需要 `NODE_OPTIONS=--openssl-legacy-provider`（webpack 4 的 md4 被 OpenSSL 3 禁了）。
> PowerShell：`$env:NODE_OPTIONS="--openssl-legacy-provider"`。

## 骰娘怎么用

群里发**小数点开头**的消息（也兼容 `.r` 前缀）：

| 规则 | 指令 | 例子 |
| --- | --- | --- |
| COC 7 版 | `.d% [困难/极难] 技能名` | `.d% 困难 侦查` → `≤ 35 成功` |
| 诡秘 D20 | `.rd20 技能名 [难度]` | `.rd20 攀爬 18` → `d20[15] + 6(力量) + 5(进阶) = 26 ≥ 18 成功` |
| 诡秘 D20（规则书原写法） | `.rd20+属性+技能 [技能名] [难度]` | `.rd20+6+2 攀爬 18` → 加值以手写为准，不再叠加人物卡 |
| 诡秘 D20（Dice! 习惯写法） | `.gm 技能 [- 加值 / 改判 / 奖励投]` | `.gm格斗+2`、`.gm格斗5`、`.gm驯兽/教育` |
| 奖励投 / 惩罚投 | `.gmb 技能` / `.gmp 技能` 或 `.gm 优势/劣势 技能` | 2d20 取高 / 取低 |
| 理智检定 | `.gmsc [成功骰/失败骰]` | `.gmsc 1/1d2`，结果可自动扣回卡片 |
| 角色卡摘要 / 先攻 | `.gmsn` / `.gmri` | 摘要：生命/灵性/敏捷/理智 |
| 生成属性 | `.诡秘 [组数]` 或 `.gm 3` | 每项 2d3（2~6），一次最多 10 组；`［a/b］` = 不含幸运/含幸运总和 |
| 伤害骰 | `.r 1d10` | 普通掷骰，不判定成功与否 |
| 查规则 / 帮助 | `.规则` / `.gm help` | 回报本团规则、实际结算方式、完整指令表 |

> ⚠️ 注意 `.gm <纯数字>` 是**生成属性**（沿用 Dice! 版语义），不是「投 d20 再 +20」。
> 想要检定请写 `.gm 技能` 或 `.rd20`：`.gm 格斗 15` = 检定格斗、难度 15。

规则优先级：**群设置（固定时）> 说话人的人物卡 > 默认 COC 7 版**。
具体数值都在人物卡里算好，玩家不用记加值。

### 骰娘设置（主持人可改）

群资料 → 主持人操作 → **「骰娘设置」**（群主和额外主持人都能改，改完广播给全群）：

| 分组 | 可改什么 |
| --- | --- |
| 功能开关 | 手动加值、奖励投/惩罚投、加值明细、大成功文案、技能模糊匹配、属性生成、理智自动扣卡、疯狂阈值警告 |
| 理智检定 | 成功扣多少（默认 `1`）、失败扣多少（默认 `1d2`）、半疯阈值（默认 ≤8）、真疯阈值（默认 ≤2） |
| 回复文案 | 检定标题、结果行、大成功文案、大失败文案（支持 `{nick}` `{target}` `{tag}` `{nat}` `{bonus}` `{total}` `{result}` `{difficulty}` 占位符） |

> 这套设置和 Dice! 版 `guimi_rule.lua` 顶部的可改变量一一对应，只是搬到了界面上。

## 主持人权限

| 角色 | 怎么来的 | 能做什么 |
| --- | --- | --- |
| **root 主持人** | 建群的人（TIM 群主） | 全部：发笔记/图片、管 BGM/场景/日志、切骰子规则、**改骰娘设置**、开机器人、导入他人人物卡、**踢人**、禁言、**解散群**、设/撤销额外主持人 |
| **额外主持人** | root 在「群资料 → 群成员」里点「设为主持人」，人数不限 | 与 root 一致地发笔记/图片、管 BGM/场景/日志、切规则、**改骰娘设置**、开机器人、导入他人人物卡；**不能踢人、不能禁言、不能解散群、不能动主持人名单** |
| **玩家** | 进群即可 | 投骰、导入/查看自己的人物卡、在「重要笔记 → 我的笔记」写自己的笔记（仅本机可见） |

主持人名单会通过高优先级消息同步给全群，刷新后仍保留（本地缓存）。

- 下面是 **主持人笔记**：root 和额外主持人在「群资料 → 发布文字/图片笔记」里发，群成员共享

## 已知限制

- **没有后端**：登录要用你自己的腾讯云 IM `SDKAppID / SecretKey`；骰娘是跑在每个玩家浏览器里的 bot 账号，页面关掉就没了
- **我的笔记只存本机**：不做云端同步，换浏览器/换设备就看不到（这是有意的，避免笔记被群成员互相看到）
- **主持人名单 / 骰娘设置靠消息同步**：新进群的玩家看不到此前的设置，让 root 在群资料里点一次「主持人名单」刷新、或重新保存一次「骰娘设置」即可
- **诡秘卡的池子是 Excel 公式**：必须用 Excel/WPS 保存过一次再导入，否则生命/防御会读成 0（导入时会提示）
- **对抗检定不自动结算**：骰娘会报出双方总值，同值时「加值高者胜、加值也相同则重投」由 KP 判
- 规则书 PDF 不入库（版权归原作者），仓库里只有空白角色卡模板
- 原项目版权归 [paotuan](https://github.com/paotuan) 作者所有，本仓库仅作个人二次开发与部署

## 原项目说明

> [paotuan.github.io](https://paotuan.github.io/) 是一个文字网团平台，囊括多种实用功能，以优化你的跑团体验。
>
> 与其他跑团平台相比，本平台借助大厂的服务资源，实现零成本的运行部署，避免了用爱发电的不可持续性，
> 并使平台核心功能的稳定性有充分保障。
>
> 理念与技术架构决定了它不会做成社交平台、不会无谓扩大功能边界，而是专注于跑团过程本身，用完即走。
>
> - 高速稳定的即时通信系统
> - 支持多种规则的骰子机器人
> - 跑团 log 的记录、编辑与导出
> - 人物卡导入、查看与快速投骰
> - 设置 BGM、发布笔记等各类实用功能
>
> 使用手册与常见问题：<https://docs.qq.com/doc/DSW1TdXhhSmdpamRX>
